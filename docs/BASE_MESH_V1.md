## 2. 座標と体型
- 身長 1.0、足裏 y=0、正面 +Z、キャラの左 +X、上 +Y、T ポーズ、左右対称
- ちびキャラ：頭 ≒ 身長の4割（あごの下 y≈0.62〜頭頂 1.0）、胴は小さく、脚は短い
- 手はミトン（指なし）、顔は凹凸なし（テクスチャで描く）
- 髪・帽子・ゴーグル・リュック・武器・アクセサリーは含まない（後で別メッシュ）

## 3. 作り方
1. 四角形ケージ（372面）を箱モデリングで組む。関節ごとにエッジループを置く：首（2）、肩・脇（胴の脇の下〜肩の2段から腕を押し出し）、肘（前後2本）、手首、股関節（股の面から脚を押し出し）、股、膝（上下2本）、足首
2. Catmull–Clark で2回細分化（全面四角形のまま。ケージの各ループは4倍になる）
3. 身長1・足裏0に正規化
4. UV はケージの面の角ごとに部位別の展開で決め、細分化では双線形に補間（継ぎ目の位置が絶対にずれない）

## 6. スキンウェイト
- 1頂点あたり最大4ボーン、合計1
- 体の中心：高さで Hips → Spine → Chest → Neck → Head になめらかに受け渡し
- 腕：肩の外側から UpperArm、肘の前後 ±0.02 で LowerArm、手首 ±0.012 で Hand。肩の上と脇の下の胴体側も一部 UpperArm（脇・肩が潰れにくい）
- 脚：股関節の上下で Hips と UpperLeg を混ぜ、膝の上下 ±0.025 で LowerLeg、足首 ±0.014 で Foot。股の中心線で左右を混ぜる
- テストポーズ：ARMS DOWN（上腕 Z ∓70°）、ELBOW 90（前腕 Y ∓90°）、KNEE 90（すね X +90°）、HIP BEND（太もも X −90°）、HEAD TURN（頭 Y 45°＋首 15°）
