# Phase 3：Visual Hull → Standard Base Mesh V1 フィッティング

場所：メイン画面 `sheet.html`（SHEET → 3D）の「5. Base Mesh フィッティング」。コード：`src/fit.ts`（計算）、`src/fitUI.ts`（画面）→ `fit.js`、`fit.css`。
Phase 1/2 のコード（`sheet.js`・`sheetParse.ts`・`hull.ts`・`sheetSpec.ts`）は変更していません。Phase 3 は `window.__sheet` で公開されている解析結果を読むだけです。

## 守ること
- Standard Base Mesh V1（`samples/e118_base_mesh_v1.glb`）を自動で読み込み、生成コードの結果と完全一致するかを確認してから使う
- 動かすのは **頂点の位置** と **ボーンの位置**（SHEET 2 の17関節）だけ。頂点数・頂点番号・面・UV・ボーン構造・ウェイトは V1 のまま
- Visual Hull は完成モデルではなく目標形状。「体の外側の上限」として使う（体は必ず Visual Hull の内側に入る）
- 最も近い点への吸着はしない。動かすのは法線方向だけで、移動量は隣どうしでならす

## 手順
1. **Joint alignment**：ボーンごとに、V1 の関節 → SHEET 2 の関節への移動・回転・長さの伸縮を作り、スキンウェイトで混ぜる。胴は肩幅・腰幅の比で横幅も合わせる。頭頂は首→頭の中心の長さから推定（髪・帽子の高さはシルエットの上端として上限にだけ使う）。指先は FRONT のシルエットが終わる位置
2. **Body proportion**：部位ごとに、前後・左右それぞれの太さを1つの倍率（輪切りの中央値）で合わせる
3. **Local body-part**：部位を輪切り（4〜10枚）にして、高さ（長さ）ごとの太さを合わせる。倍率は輪切りの間でなめらかにつなぐ。腕・脚の付け根は倍率を弱めて、脇・股が潰れないようにする
4. **Visual Hull surface**：Visual Hull はボクセルで削った形で角や段差があるため、境界から 0.006 までのはみ出しは許す。それ以上はみ出した頂点だけ境界近くまで法線の内側へ戻す（最大 0.05）。内側の頂点は、境界が 0.008 以内のときだけ半分寄せる。移動量は隣どうしで広くならす（6回）。面が裏返る動きは取り消す
5. **Smoothing / regularization**：移動量を広くならし（8回）、Taubin 平滑化（10回。細かい凸凹だけ消して全体は縮ませない）、左右対称のキャラは中心面で左右を平均、裏返りをほどく、大きくはみ出した頂点だけ戻す

輪切りの太さは、1枚だけ飛び出した値を中央値で消してからならし、胴（腰・背骨・胸）・腕・脚はボーンの境目をまたいでつなげてならす。

## 体に含めないもの（装備の除外）
- 胴の横幅：肩の関節の幅で上限（T ポーズの腕の影や装備を除外）
- 脚の内側：体の中心線を越えない（左右の脚の重なりを除外）
- 測った太さが今の形の 1.8 倍を超える／0.35 倍未満の輪切りは、装備・重なりとみなして使わず、前後の輪切りから補う（リュック、腕と胴の重なりなど）
- 頭の太さの倍率は 1.35 倍まで（髪・帽子で頭を膨らませない）
- 髪・帽子・服・ゴーグル・リュック・武器・アクセサリーは、今後 PARTS から別メッシュとして扱う
