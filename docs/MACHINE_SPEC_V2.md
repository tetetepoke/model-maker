# ELEMENT 118 3D-SHEET V2 MACHINE SPEC

Element 118 のキャラクター3D化用・設計シート2枚の機械解析仕様（V2）。
V1 との違い：**完全透過PNGだけで構成**し、枠・白背景・タイトル・説明文は不要。SHEET 2 は**骨格・関節専用**。
アプリ（3D MODEL MAKER の sheet.html）は V1 / V2 を自動で読み分ける（選択は不要）。

---

## 0. 役割の分離（固定）

| シート | 使うもの | 使わないもの |
|---|---|---|
| SHEET 1 | 外観・シルエット・3D形状・色・パーツ | 関節（マーカーを描いても読まない） |
| SHEET 2 | 骨格・関節座標（17関節＋奥行き9個） | 外観・色・テクスチャ |

## 1. 共通ルール

1. **PNG・背景は完全透過**（キャラ以外のすべての画素がアルファ0）。
2. 枠・タイトル・ラベル・説明文は**描かない**（描く場合も細く小さく、キャラから離す。解析は無視する）。
3. 影・床・台座・パネル・背景の塗りつぶしは**描かない**。
4. 横長。**推奨 2400×1350（16:9）**、長辺1500px以上。
5. 全ビュー**正投影・Tポーズ**（腕は真横・水平、手のひら下、脚はまっすぐ、足は肩幅）。
6. 絵同士は離す（シート幅の1.5%以上のすき間）。

### 左右の定義（固定）

すべて**キャラクター本人から見た左右**。
- `_L` = キャラ本人の左。正面図では**画像を見る人から見て右側**。
- RIGHT ビュー = キャラ本人の右側から見た図（**顔は画像の右**向き）。LEFT ビュー = 左側から（**顔は画像の左**向き）。
- BACK = 背中側から（キャラの右手が画像の右）。TOP = 真上から（**正面が画像の下**、キャラの左手が画像の右）。
- 3D座標：正面 = +Z、キャラ本人の左 = +X、上 = +Y。

## 2. SHEET 1：APPEARANCE / SHAPE（完全透過）

配置（シート全体を0〜1とした目安。数十pxのズレは解析側で吸収する）：

| ビュー | 置く位置（中心） | 条件 |
|---|---|---|
| FRONT | x ≈ 0.125、上段 | 全身。身長はシート高さの約40% |
| RIGHT | x ≈ 0.375、上段 | 顔は画像の右 |
| BACK | x ≈ 0.625、上段 | |
| LEFT | x ≈ 0.875、上段 | 顔は画像の左 |
| TOP | x ≈ 0.125、下段（y ≈ 0.86） | 横幅は FRONT と同じ（同じ縮尺） |
| PARTS | 下段、x 0.25〜1.0 を6等分した各中央 | 左から HAIR, HAT, BACKPACK, WEAPON, ACCESSORY, EXTRA。無いものは空ける |

- FRONT / RIGHT / BACK / LEFT の4体は**同一キャラ・同一縮尺・同一身長（±10%以内）・足底の高さ統一**（上段の y ≈ 0.69 に足底）。
- 上段4体の頭頂も同じ高さ（y ≈ 0.29）。Tポーズの腕先まで含めて、隣の絵と重ならないこと（各ビューの横幅はシート幅の約21%まで）。
- PARTS は位置（6等分）でIDを判定する。外れた場合は解析画面で付け替えできる。

解析：アルファ ≥ 100 を前景 → 細い線を除去 → 塊を検出 → 上段の背の高い4体を左から FRONT / RIGHT / BACK / LEFT、下段左の FRONT 幅の塊を TOP、残りを PARTS → 足底・頭頂・中心軸で正規化。

## 3. SHEET 2：STRUCTURE / RIG（完全透過・骨格専用）

**配置は固定**（横方向の割合）：

| 範囲 | 内容 |
|---|---|
| 左 0〜40% | **JOINT FRONT**：Tポーズ正面の人体シルエット＋17マーカー |
| 中央 40〜60% | **JOINT RIGHT**：右側面（顔は画像の右）の人体シルエット＋9マーカー |
| 右 60〜100% | REFERENCE（BONE / MESH / UV など）または空白。**解析しない** |

- 人体は**キャラの完成イラストでなくてよい**。SHEET 1 の体型に合わせた**単色シルエット**。
- シルエットの色は**明るいグレー（#D0D0D0〜#E6E6E6）推奨**。鮮やかな色（彩度の高い色）は使わない。服・模様・アクセサリーは描かない。
- 各範囲の中で、人体はその範囲の**左右中央**、高さはシート高さの約55〜60%。範囲の境界をはみ出さない。
- 骨格線を描いてよい：**白・黒・グレー推奨**、太さは**マーカー直径の1/4以下**（細い線は解析で除去される。同じ色でも可）。
- JOINT FRONT と JOINT RIGHT の身長は同じ。

## 4. 関節マーカー

- **塗りつぶしの円**、直径 = **身長の3%**（2.5〜4%可）、中心 = 関節の中心。縁取りは黒1〜2pxまで。白リング・二重丸・文字の重ね書きは禁止。
- マーカー同士を重ねない（RIGHT 図の例外は下記）。

| ID | HEX | RGB | 位置（足底0〜頭頂1） | FRONT図の横位置 |
|---|---|---|---|---|
| HEAD | #FF00FF | 255,0,255 | 0.60–1.00 | 中央 |
| NECK | #00FFFF | 0,255,255 | 0.45–0.92 | 中央 |
| CHEST | #FFFF00 | 255,255,0 | 0.35–0.85 | 中央 |
| SPINE | #FF8000 | 255,128,0 | 0.25–0.75 | 中央 |
| HIPS | #8000FF | 128,0,255 | 0.15–0.65 | 中央 |
| SHOULDER_L / _R | #FF0000 | 255,0,0 | 0.35–0.90 | _L 画像の右 / _R 画像の左 |
| ELBOW_L / _R | #00FF00 | 0,255,0 | 0.25–0.90 | 〃 |
| WRIST_L / _R | #0000FF | 0,0,255 | 0.15–0.90 | 〃 |
| HIP_L / _R | #00FF80 | 0,255,128 | 0.10–0.60 | 〃 |
| KNEE_L / _R | #FF0080 | 255,0,128 | 0.03–0.40 | 〃 |

- **JOINT FRONT：17個すべて**描く（左右の対は同じ色）。
- **JOINT RIGHT：9個**——HEAD, NECK, CHEST, SPINE, HIPS, SHOULDER, HIP, KNEE, ANKLE（左右の対は重なるので1個。腕は肩・肘・手首が重なるので SHOULDER だけ）。
- 色は表の値のまま（黄色を金色・オレンジ寄りにしない）。解析の許容：色相 ±14°、鮮やかさ（RGB最大−最小）90以上、明るさ110以上。
