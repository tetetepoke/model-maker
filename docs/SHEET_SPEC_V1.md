# Element 118 Sheet V1 規格（E118-SHEET-V1）

Element 118 のキャラクター3D化に使う「設計シート2枚」の正式規格。
3D MODEL MAKER の「設計シート」ページはこの規格を前提に自動解析する。
コード上の定義は `src/sheetSpec.ts`（この文書と同じ値）。

---

## 0. 共通ルール

| 項目 | 規格 |
|---|---|
| 枚数 | 2枚（SHEET 1 / SHEET 2） |
| 形式 | PNG、**背景は完全透過**（透過できない場合は単色の背景。白推奨） |
| 縦横比 | **16:9（横長）**。推奨 3840×2160（最低 1920×1080） |
| 投影 | 正投影（遠近感なし） |
| 姿勢 | **全ビューで T ポーズ**（腕は真横・水平、手のひらは下、脚はまっすぐ、足は肩幅程度に開く） |
| 縮尺 | 全ビュー同一縮尺。**身長はセルの高さの約60%**、Tポーズの腕先まで含めてセルの横幅の90%以内に収める（腕が長いキャラは全体を小さく） |
| 足底 | 全ビューで同じ高さ（セル下端から約5%上の線） |
| 頭頂 | 全ビューで同じ高さ |
| 中心軸 | 各セルの左右中央にキャラの中心軸を置く |
| ラベル | 各セルの**上端7%の帯の中**に文字で書く（解析では無視される）。キャラや装備をこの帯に入れない |
| 禁止 | セル同士にまたがる絵、影・床・背景の描き込み、ビューごとに違う縮尺、カメラの傾き |

座標の約束（3Dに直したときの向き）：キャラの正面 = +Z、キャラの左 = +X、上 = +Y。

## 1. SHEET 1：APPEARANCE / SHAPE

```
 ┌──────────────────────────────────────────────────────────────┐  0%
 │ ELEMENT 118  SHEET V1  APPEARANCE / SHAPE   (タイトル帯)        │
 ├──────────────┬──────────────┬──────────────┬──────────────┤  6%
 │   FRONT      │   RIGHT      │   BACK       │   LEFT       │
 │              │              │              │              │
 │   (正面)      │ (右側面)      │  (背面)       │ (左側面)      │
 │              │              │              │              │
 ├──────────────┼──────┬──────┬──────┬──────┬──────┬──────┤  72%
 │   TOP        │ HAIR │ HAT  │BACK- │WEAPON│ACCES-│EXTRA │
 │  (上面)       │      │      │ PACK │      │ SORY │      │
 └──────────────┴──────┴──────┴──────┴──────┴──────┴──────┘  100%
 0%            25%           50%           75%           100%
```

| セル | 範囲（横 x / 縦 y、シート全体に対する%） | 見え方 |
|---|---|---|
| FRONT | x 0–25 / y 6–72 | 正面から。キャラの左手は**画面の右** |
| RIGHT | x 25–50 / y 6–72 | キャラの**右側**から。顔は**画面の右**を向く |
| BACK | x 50–75 / y 6–72 | 背面から。キャラの右手は画面の右 |
| LEFT | x 75–100 / y 6–72 | キャラの**左側**から。顔は**画面の左**を向く |
| TOP | x 0–25 / y 72–100 | 真上から。**正面が画面の下**、キャラの左手は画面の右 |
| PARTS | x 25–100 / y 72–100 を横に6等分 | 左から HAIR, HAT, BACKPACK, WEAPON, ACCESSORY, EXTRA |

- TOP も FRONT と同じ縮尺（TOP の横幅 = FRONT の横幅）。
- PARTS：各スロットに、そのパーツ**だけ**を正面向きで描く。無いパーツのスロットは空欄のまま（何も描かない）。
- 色・模様・顔はこのシートから取る。本体の配色は自由。

## 2. SHEET 2：STRUCTURE / RIG

```
 ┌──────────────────────────────────────────────────────────────┐  0%
 │ ELEMENT 118  SHEET V1  STRUCTURE / RIG      (タイトル帯)        │
 ├────────────────────────┬────────────┬────────────┬────────────┤  6%
 │ T-POSE /               │ JOINT      │ BONE       │ MESH       │
 │ JOINT MARKERS FRONT    │ MARKERS    │ REFERENCE  │ REFERENCE  │
 │                        │ RIGHT      ├────────────┴────────────┤  53%
 │                        │            │ UV REFERENCE            │
 └────────────────────────┴────────────┴─────────────────────────┘  100%
 0%                      40%          60%          80%         100%
```

| セル | 範囲 | 内容 | 解析 |
|---|---|---|---|
| JOINT MARKERS FRONT | x 0–40 / y 6–100 | T ポーズ正面の体を**明るいグレー単色**（#D0D0D0〜#E6E6E6）で塗り、関節マーカーを描く | 使う |
| JOINT MARKERS RIGHT | x 40–60 / y 6–100 | 右側面（顔は画面の右）を同じグレーで塗り、関節マーカーを描く | 使う |
| BONE REFERENCE | x 60–80 / y 6–53 | ボーンの参考図 | 使わない（人が確認する用） |
| MESH REFERENCE | x 80–100 / y 6–53 | ワイヤーフレームの参考図 | 使わない（トポロジーには Element 118 Base Mesh を使う） |
| UV REFERENCE | x 60–100 / y 53–100 | UV の参考図 | 使わない |

- JOINT MARKERS の2セルでは、**体をグレー単色にし、マーカー以外に鮮やかな色を使わない**（誤検出防止）。
- 2セルとも SHEET 1 と同じ姿勢・同じ比率（頭頂〜足底の高さで正規化して照合する）。

## 3. 関節マーカー（色＋固定ID＋位置）

- 形：**塗りつぶしの円**、グラデーション・模様なし。縁に1〜2pxの黒線は可。
- 大きさ：**直径 = 身長の3%**（身長 1200px なら直径 36px）。
- 位置：円の中心 = 関節の中心。
- 左右の対（_L/_R）は**同じ色**。FRONT では**画面の右にある方が _L**（キャラの左）。
- RIGHT 図では左右の対が重なるので**1個だけ**描く（手前＝右側のもの）。
- RIGHT 図では T ポーズの腕の **SHOULDER・ELBOW・WRIST が同じ位置に重なるので SHOULDER だけ**描く（肘・手首の奥行きは肩と同じとして扱う）。

| ID | RGB（固定） | 16進 | FRONT での位置の目安（足底0〜頭頂1） |
|---|---|---|---|
| HEAD | 255, 0, 255 | #FF00FF | 頭の中心（0.6〜1.0） |
| NECK | 0, 255, 255 | #00FFFF | 首の付け根（0.45〜0.92） |
| CHEST | 255, 255, 0 | #FFFF00 | 胸の中心（0.35〜0.85） |
| SPINE | 255, 128, 0 | #FF8000 | みぞおち〜へそ（0.25〜0.75） |
| HIPS | 128, 0, 255 | #8000FF | 骨盤の中心（0.15〜0.65） |
| SHOULDER_L / _R | 255, 0, 0 | #FF0000 | 肩関節（0.35〜0.9） |
| ELBOW_L / _R | 0, 255, 0 | #00FF00 | 肘（0.25〜0.9） |
| WRIST_L / _R | 0, 0, 255 | #0000FF | 手首（0.15〜0.9） |
| HIP_L / _R | 0, 255, 128 | #00FF80 | 股関節（0.1〜0.6） |
| KNEE_L / _R | 255, 0, 128 | #FF0080 | 膝（0.03〜0.4） |
| ANKLE_L / _R | 0, 128, 255 | #0080FF | 足首（−0.02〜0.2） |

検出ルール（アプリ側）：

- 色距離（RGB のユークリッド距離）が **60 以内**ならその色とみなす（色同士の間隔は約127あるので重ならない）。
- 彩度（最大−最小）が **140 未満**の画素は無視（グレーの体やアンチエイリアスの縁を除外）。
- 面積が「直径3%の円」の **15%未満**の塊は無視。
- 上の表の高さ範囲から外れたものは採用しない。
- 見つからない関節はシルエットから推定し、画面に警告を出す。**すべての関節は画面上で指で動かして修正できる。**

## 4. ChatGPT への依頼文（テンプレート）

> Element 118 Sheet V1 規格で、キャラクター「（名前）」の設計シートを2枚作ってください。
> 共通：PNG・背景完全透過・16:9・正投影・全ビューTポーズ・同一縮尺・足底と頭頂の高さを全ビューで統一・各セルの左右中央に中心軸・ラベルは各セル上端7%の帯の中だけ。
> SHEET 1（APPEARANCE / SHAPE）：上段を横4等分して左から FRONT / RIGHT（顔は画面右向き）/ BACK / LEFT（顔は画面左向き）、下段の左1/4に TOP（正面が画面下）、下段の残りを6等分して左から HAIR / HAT / BACKPACK / WEAPON / ACCESSORY / EXTRA（無いものは空欄）。
> SHEET 2（STRUCTURE / RIG）：左40%に T-POSE 正面、その右20%に右側面。どちらも体を明るいグレー単色で塗り、関節マーカーを直径＝身長の3%の塗りつぶし円で描く。色は HEAD #FF00FF、NECK #00FFFF、CHEST #FFFF00、SPINE #FF8000、HIPS #8000FF、SHOULDER #FF0000、ELBOW #00FF00、WRIST #0000FF、HIP #00FF80、KNEE #FF0080、ANKLE #0080FF（左右は同色、右側面図では重なる対は1個、腕は SHOULDER だけ）。マーカー以外に鮮やかな色を使わない。右上に BONE REFERENCE と MESH REFERENCE、右下に UV REFERENCE（参考図）。

アプリの「サンプルで試す」で読み込めるサンプル（`samples/`）が、この規格どおりの見本。
