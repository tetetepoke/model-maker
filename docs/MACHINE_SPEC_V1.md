# ELEMENT 118 3D-SHEET V1 MACHINE SPEC

Element 118 のキャラクター3D化に使う設計シート（2枚）を、画像生成AIで作るための機械解析仕様。
この仕様どおりに作れば、3D MODEL MAKER（sheet.html）の自動解析がそのまま読み取れる。
数px〜数十pxの位置ズレ、RGBの多少のズレは解析側で吸収する（完全なピクセル一致は不要）。

---

## 0. 絶対ルール（これを破ると認識に失敗する）

1. **背景は完全透過PNG**。透過できない場合は**真っ白（#FFFFFF）の単色**。グラデーション・模様・紙の質感は禁止。
2. **キャラクターの後ろにパネル・カード・塗りつぶしの四角・影・床・台座を描かない**。セルは「細い線の枠」だけ。
   （塗りつぶしの四角はキャラクターより大きな「絵の塊」と判定され、本物のキャラクターが除外される）
3. **全身ビュー（FRONT / RIGHT / BACK / LEFT）は4体とも同じ大きさ**（身長の差は±10%以内）。
   （いちばん背の高い塊の60%未満の絵は全身ビューとみなされない）
4. 絵と絵、絵と枠・文字は**離す**（シート幅の1.5%以上のすき間）。触れていると1つの塊になる。
5. 枠線・ガイド線・寸法線は**細く**（画像の短辺の0.3%以下。1024pxなら3px以下）。文字の線も同じく細く、文字の高さは短辺の2.5%以下。
6. 全ビュー**Tポーズ**（腕は真横・水平、手のひら下、脚はまっすぐ、足は肩幅）。**正投影**（遠近感なし）。
7. SHEET 2 の JOINT MARKERS 図では、**体は明るいグレー単色**、マーカー以外に鮮やかな色を一切使わない。参考図（BONE / MESH / UV）も白・黒・グレーだけで描く。

## 1. 共通

| 項目 | 規格 |
|---|---|
| 形式 | PNG（透過）。不可なら白背景 |
| サイズ | 横長。**推奨 2400×1350（16:9）**。3:2（1536×1024 等）も可。長辺1500px以上 |
| 座標系（3D） | キャラの正面 = +Z、**キャラ本人の左 = +X**、上 = +Y |
| 正規化 | 解析は各ビューを「足底 = 0、頭頂 = 1、中心軸 = 左右中央」に正規化する |

### 左右の定義（Element 118 で固定）

- **すべて「キャラクター本人から見た左右」**。
- `SHOULDER_L` など `_L` は**キャラ本人の左**。FRONT 図では**画像を見る人から見て右側**に描かれる。
- **RIGHT ビュー** = キャラ本人の**右側から**見た図。**顔は画像の右を向く**。
- **LEFT ビュー** = キャラ本人の**左側から**見た図。**顔は画像の左を向く**。
- **BACK ビュー** = 背中側から。キャラ本人の右手が画像の右側。
- **TOP ビュー** = 真上から。**キャラの正面が画像の下**、キャラ本人の左手が画像の右側。

## 2. SHEET 1：APPEARANCE / SHAPE

### 配置（シート全体を 0〜1 に正規化した座標。解析は位置ズレを吸収するが、この配置で作る）

```
y=0.00 ┌─────────────────────────────────────────────┐
       │ タイトル（細い文字）                           │
y=0.06 ├──────────┬──────────┬──────────┬──────────┤
       │  FRONT   │  RIGHT   │  BACK    │  LEFT    │
       │          │ 顔→右    │          │ 顔←左    │
y=0.72 ├──────────┼────┬────┬────┬────┬────┬────┤
       │  TOP     │HAIR│HAT │BACK│WEAP│ACCE│EXTR│
y=1.00 └──────────┴────┴────┴────┴────┴────┴────┘
      x=0      0.25   0.375 0.5 0.625 0.75 0.875  1.0
```

| 領域 | セル（x / y） | キャラの外接矩形の目安（x / y） |
|---|---|---|
| FRONT | 0.00–0.25 / 0.06–0.72 | 0.02–0.23 / 0.29–0.69 |
| RIGHT | 0.25–0.50 / 0.06–0.72 | 中心 x=0.375、y 0.29–0.69（幅は細い） |
| BACK | 0.50–0.75 / 0.06–0.72 | 0.52–0.73 / 0.29–0.69 |
| LEFT | 0.75–1.00 / 0.06–0.72 | 中心 x=0.875、y 0.29–0.69 |
| TOP | 0.00–0.25 / 0.72–1.00 | 中心 (0.125, 0.86)、横幅は FRONT と同じ |
| PARTS ×6 | 0.25–1.00 を6等分 / 0.72–1.00 | 各セルの中央 |

- **身長はセルの高さの約60%**（全身ビュー4体とも同じ）。**足底の高さは4体とも同じ**（セル下端から5%上）。
- Tポーズの腕先まで含めてセル幅の90%以内に収める。
- **TOP は FRONT と同じ縮尺**（TOP の横幅 = FRONT の横幅、許容 0.6〜1.6倍）。高さ（奥行き方向）は全身ビューの60%未満になるはず。
- ラベル（FRONT 等）は各セルの**上端7%の帯**に細い文字で。キャラに触れさせない。

### PARTS

- 6つのセルを、**空欄も含めて必ず細い線の枠で囲む**（解析は枠を左から数えてスロットを決める）。
- 左から **HAIR, HAT, BACKPACK, WEAPON, ACCESSORY, EXTRA**。各セルにそのパーツ**だけ**を正面向きで、セル中央に描く。無いパーツは空欄（枠だけ）。
- 将来の固定ID（解析画面で付け替え可）：HAIR, HEAD, FACE, HAT, GOGGLES, SCARF, UPPER_CLOTH, LOWER_CLOTH, BELT, BACKPACK, SHOES, WEAPON, ACCESSORY, EXTRA。

## 3. SHEET 2：STRUCTURE / RIG

```
y=0.00 ┌──────────────────────────────────────────────┐
       │ タイトル                                        │
y=0.06 ├──────────────────┬─────────┬────────┬────────┤
       │ T-POSE /          │ JOINT   │ BONE   │ MESH   │
       │ JOINT MARKERS     │ MARKERS │ REF    │ REF    │
       │ FRONT             │ RIGHT   ├────────┴────────┤ y=0.53
       │                   │         │ UV REFERENCE    │
y=1.00 └──────────────────┴─────────┴─────────────────┘
      x=0               0.40      0.60     0.80      1.0
```

| 領域 | セル（x / y） | 解析での扱い |
|---|---|---|
| JOINT MARKERS FRONT | 0.00–0.40 / 0.06–1.00 | **使う**。Tポーズ正面。体はグレー単色＋マーカー。外接矩形の**縦横比（幅÷高さ）は 0.6 より大きく**（Tポーズなら自然にそうなる） |
| JOINT MARKERS RIGHT | 0.40–0.60 / 0.06–1.00 | **使う**。右側面（顔は画像の右）。グレー単色＋マーカー。**縦横比は 0.6 以下** |
| BONE / MESH / UV REFERENCE | 0.60–1.00 | 使わない（人が見る参考図）。白・黒・グレーのみ、背は JOINT 図の半分以下 |

- JOINT 図2つの身長は同じ（SHEET 1 と同じでなくてよい。身長で正規化する）。
- 体のグレー：#D0D0D0〜#E6E6E6、塗りつぶし、模様なし。

## 4. 関節マーカー

### 形・大きさ

- **塗りつぶしの円**。直径 = **身長の3%**（2.5〜4%の範囲なら可）。縁取りは黒1〜2pxまで。白いリング・二重丸・文字の重ね書きは禁止。
- 円の中心 = 関節の中心。マーカー同士は重ねない（RIGHT 図の例外は下記）。

### 色と位置（u = 中心軸からの横位置 ÷ 身長、v = 足底からの高さ ÷ 身長）

| ID | RGB | HEX | 色相 | 許容 | 位置（v＝高さ） | 位置（u＝横、FRONT図） |
|---|---|---|---|---|---|---|
| HEAD | 255,0,255 | #FF00FF | 300° | 色相±14° | 0.60–1.00 | 中央（\|u\|<0.12） |
| NECK | 0,255,255 | #00FFFF | 180° | 〃 | 0.45–0.92 | 中央 |
| CHEST | 255,255,0 | #FFFF00 | 60° | 〃 | 0.35–0.85 | 中央 |
| SPINE | 255,128,0 | #FF8000 | 30° | 〃 | 0.25–0.75 | 中央 |
| HIPS | 128,0,255 | #8000FF | 270° | 〃 | 0.15–0.65 | 中央 |
| SHOULDER_L / _R | 255,0,0 | #FF0000 | 0° | 〃 | 0.35–0.90 | _L：画像の右（u>0）／_R：画像の左（u<0） |
| ELBOW_L / _R | 0,255,0 | #00FF00 | 120° | 〃 | 0.25–0.90 | 〃 |
| WRIST_L / _R | 0,0,255 | #0000FF | 240° | 〃 | 0.15–0.90 | 〃 |
| HIP_L / _R | 0,255,128 | #00FF80 | 150° | 〃 | 0.10–0.60 | 〃 |
| KNEE_L / _R | 255,0,128 | #FF0080 | 330° | 〃 | 0.03–0.40 | 〃 |
| ANKLE_L / _R | 0,128,255 | #0080FF | 210° | 〃 | −0.02–0.20 | 〃 |

- **色は上の値をそのまま使う**。黄色を金色・オレンジ寄りにしない（CHEST の黄色 60° が 46° 以下になると認識できない）。
- 色の判定条件：色相が規格±14°、鮮やかさ（RGBの最大−最小）90以上、明るさ（最大値）110以上。暗くしすぎない。
- 左右の対は同じ色。左右は FRONT 図での位置で決まる（画像の右 = キャラ本人の左 = _L）。

### RIGHT 図（奥行き）

- 左右の対は重なるので1個だけ描く。
- **腕は SHOULDER だけ描く**（Tポーズでは肩・肘・手首が重なるため。肘・手首の奥行きは肩と同じとして扱う）。
- HEAD, NECK, CHEST, SPINE, HIPS, SHOULDER, HIP, KNEE, ANKLE の9個を描く。

## 5. 画像生成AIへの依頼文（コピー用）

> 「ELEMENT 118 3D-SHEET V1 MACHINE SPEC」に厳密に従い、キャラクター「（名前）」の設計シートを2枚（SHEET 1：APPEARANCE / SHAPE、SHEET 2：STRUCTURE / RIG）作ってください。
> 背景は完全透過PNG（不可なら真っ白単色）。キャラの後ろにパネル・カード・塗りつぶし・影・床を描かず、セルは細い線の枠だけ。全ビュー正投影・Tポーズ。全身ビュー4体（FRONT / RIGHT 顔は画像の右向き / BACK / LEFT 顔は画像の左向き）は同じ大きさ・同じ足底の高さ・身長はセル高さの約60%。下段左に TOP（正面が画像の下、FRONTと同じ横幅）、下段右は細い枠の6セル（HAIR, HAT, BACKPACK, WEAPON, ACCESSORY, EXTRA。無いものは空の枠）。絵と枠・文字は離す。枠と文字は細く小さく。
> SHEET 2：左40%にTポーズ正面、その右20%に右側面。体は明るいグレー単色。関節マーカーは直径＝身長の3%の塗りつぶし円で、色は HEAD #FF00FF、NECK #00FFFF、CHEST #FFFF00、SPINE #FF8000、HIPS #8000FF、SHOULDER #FF0000、ELBOW #00FF00、WRIST #0000FF、HIP #00FF80、KNEE #FF0080、ANKLE #0080FF（左右同色、_L はキャラ本人の左＝正面図で画像の右）。右側面図では腕は SHOULDER だけ、左右の対は1個。マーカー以外に鮮やかな色を使わない。右側の BONE / MESH / UV 参考図は白黒グレーのみで小さく。

## 6. 解析側の処理（参考：この順で読み取る）

1. 前景：透過ピクセルが5%超ならアルファ（≥100を前景）。そうでなければ外周の色（中央値）から距離40以内で外周につながる部分を背景。
2. 線の除去：半径 = 短辺×0.4% の収縮→膨張（オープニング）で細い線・文字を消す。
3. 塊：面積が画像の0.12%以上、かつ塗りの密度（面積÷外接矩形）10%以上。小さい塊が大きい塊の範囲内（3%の余白）にあればまとめる。
4. SHEET 1 全身ビュー：いちばん背の高い塊の60%以上の高さ、かつ足元の高さが中央値から最大高さの35%以内 → 左から FRONT / RIGHT / BACK / LEFT（4体を超えたら面積の大きい4体）。
5. TOP：全身ビューより下で、横幅が FRONT の0.6〜1.6倍、高さが最大の60%未満の塊のうち左端。
6. PARTS：残りの下段の塊。PARTS の枠が6個以上あれば枠の順、なければ TOP 枠の右端〜画像右端を6等分。
7. SHEET 2：背の高さが最大の50%以上でマーカー色を含む塊のうち、縦横比>0.6でマーカーが最多 = JOINT FRONT、≤0.6でマーカーが最多 = JOINT RIGHT。
8. マーカー：色相判定 → 塊 → 形（縦横比0.5〜2、塗り45%以上、面積は規格円の0.12〜6倍）→ 位置（上の表）→ 同じIDで最大のもの。RIGHT 図では高さが±0.08以内の同色マーカーで奥行きを決める。
9. 見つからない関節は SHEET 2 の正面シルエットから推定し、画面上で指で修正する。
