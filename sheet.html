43D生成（Visual Hull）

5方向のシルエットの共通部分を削り出した「形状測定用」の立体です。次の段階でこれを目標に Element 118 Base Mesh を変形します（これ自体は最終キャラではありません）。

品質
ずれの許容

「ずれの許容」は、ビュー同士の絵が少しずれていて腕や脚が欠ける時だけ上げてください（上げるほど全体が太ります）。一致しないビューはチェックを外して除外できます。

5Base Mesh フィッティング（Phase 3）

Standard Base Mesh V1 を自動で読み込み、SHEET 2 の17関節と Visual Hull に合わせて「頂点の位置」だけを動かします。頂点数・頂点番号・面・UV・ボーン構造は V1 のままです。Visual Hull は目標形状（体の外側の上限）としてだけ使い、髪・帽子・リュックなどは体に含めません。

結果は上の3D画面に出ます。Original Sheets は FRONT〜TOP の時だけ元の絵を重ねます。Overlay は Visual Hull を青い半透明で重ねます。指で回すと自由視点（FREE）です。
